- Added same-name exclusions for Japanese encephalitis virus and the Journal of Extracellular Vesicles.

- This is a dated seed snapshot, not a claim of complete internet coverage.
- X records that could not be fetched directly remain at probable evidence and retain the access limitation.
- GitHub stars, forks, issue counts, prices, and model versions are not stored as timeless facts; any later metric must include an `as_of` date and a source URL.
- A Xiaohongshu search lead and one unstable Chinese-language article remain in `data/pending_review.json`; neither is presented as an established record.

### Limited source fetches

- `source:typesafe-x`: the account-level page was available, but individual linked statuses were not consistently machine-readable.
- `source:x-matija-jev`: the original status was not directly machine-readable; the linked archive is retained as a secondary evidence source.
- These are record-level access limitations, not claims that the channels or posts do not exist; `state/last_run.json` therefore keeps `failedSources` empty.

### Maintenance

- `state/last_run.json` records the successful review window and sources checked.
- Future reviews should read the previous snapshot, preserve changes and exclusions, and run `npm run validate` before publication.
